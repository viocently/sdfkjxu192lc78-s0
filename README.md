This repo contains our source code for CMP-related works. 

The folder "eurocrypt2024" is the source code for the paper "Massive Superpoly Recovery with a Meet-in-the-middle Framework -- Improved Cube Attacks on Trivium and Kreyvium" published in EUROCRYPT 2024. 

The folder "ctp2026" is the source code for the subsequent paper "Exploring Core Monomial Prediction Further: Weak-Key Superpoly Recovery for 852-Round Trivium" we submitted to CTP.
